记录是怎么存的?

每次检测完成后,报告以 JSON 落盘到本服务的数据目录(<protocol>/<job_id>.json), 重启服务也不会丢。报告里的 API key 是脱敏形式(sk-y7xU••••••0h), 明文 key 只在内存里存活到检测结束。 JSON 接口见 GET /api/jobs,便于接入自己的监控或归档流程。
